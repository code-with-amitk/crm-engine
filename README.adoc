== Overview

This documentation provides a comprehensive technical reference for the CRM Backend application. The CRM system is built using Go, PostgreSQL, and containerized with Docker, designed to manage sales pipelines, leads, employee workflows, and multi-tenant operations.

== Key Features

* *Multi-Tenant Architecture*: Secure logical isolation of tenant data
* *JWT & Refresh Token based Authentication*: Stateless authentication with token refresh mechanism
* *Rate Limiting*: Distributed-ready rate limiting (login & user-level)
* *Real-time Notifications*: Expo Push Notifications integration for mobile alerts
* *Comprehensive Logging*: Structured JSON logging with Zap
* *API Security*: CORS support, SSL/TLS termination via Nginx reverse proxy
* *Database Reliability*: Connection pooling, transaction management, cascading deletes
* *Scalable Deployment*: Docker Compose for local development, ready for Kubernetes

== Technology Stack

[cols="20%,35%,45%"]
|===
| Component | Technology | Purpose

| Runtime | Go 1.24 | Backend API and services
| Database | PostgreSQL 16 | Primary data store
| Web Framework | Gorilla Mux | HTTP routing
| Authentication | JWT (HS256) | Stateless authentication
| Logging | Zap (Uber) | Structured logging
| Containerization | Docker Compose | Local dev & deployment
| Reverse Proxy | Nginx | SSL termination & routing
| Notifications | Expo Push | Mobile push notifications
| Observability | Grafana + Loki | Logging & monitoring
|===

== System Requirements

=== Development Environment

* Go 1.24 or higher
* PostgreSQL 16 or compatible
* Docker & Docker Compose
* Git

=== Production Deployment

* Kubernetes 1.28+ (or Docker Swarm)
* PostgreSQL 16 with backups
* Nginx/Reverse proxy with SSL
* 2+ GB RAM per container
* At least 50 GB storage for database
